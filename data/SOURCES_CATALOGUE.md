# Provenance de data/catalogue.csv (relevé du 26/11/2026)

- **Noms, contenus, variantes** : pokemon.com/fr, article « JCC Pokémon : produits 30ᵉ Anniversaire »
  et galeries produits. Les 3 Pokébox ne figurent pas dans cet article : elles viennent de lecrocodeal.com.
- **EAN** : pages « où acheter » de lecrocodeal.com, relues une par une. Toutes les clés de contrôle sont valides.
  Recoupements : ETB (Pokepedia), lot de 6 boosters (Play-in), figurine Mewtwo (Play-in).
- **ASIN** : fiches amazon.fr ouvertes une à une ; titre en VF conforme au produit
  (UPC Journée, UPC Soirée, figurine Mew, figurine Mewtwo).
  B0H8SSRSV7 (« Collection de Figurines 30e célébration — Mewtwo ») est écarté : libellé d'import.
- **EAN Collection Premium Métamorph** (0196214147430, clé valide) : infobox Poképédia, lue par son API.
  Source unique, pas encore recoupée.
- **Laissés vides faute de source fiable** :
  - Collection K.O. : aucun EAN trouvé.
  - Decks Combat Mentali-ex et Noctali-ex : Play-in affiche le même code pour les deux variantes.
  - Tous les autres ASIN.
- **Prix conseillé** : non renseigné. Seules des fourchettes d'enseignes existent (CrocoDeal), pas de PVC officiel.
